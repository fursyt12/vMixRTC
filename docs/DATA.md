# Источники данных: Google Sheets, Excel, HTTP API, XML, JSON, NDI

Данные в vMixRTC приходят через **провайдер** и раскладываются по элементам тайтлов vMix.
Виджет с источником — это либо «Внешние данные», либо «Список»; строки можно и просто
вписать руками (см. «Список из рук» в конце).

## Как добавить источник: 5 шагов

1. Выберите виджет и откройте **Свойства** (⚙ или правый клик → «Свойства…»).
2. Если источника ещё нет — нажмите **«Добавить источник данных»**.
3. В поле **«Провайдер данных»** выберите тип: XML/HTTP, JSON, Excel, Google Sheets, NDI или Файлы.
4. Заполните поля провайдера (они появляются сразу после выбора) и при желании период опроса.
5. Нажмите **«Обновить сейчас»** — под кнопкой появится количество строк или текст ошибки.
   Кнопка **«Показать строки источника»** открывает таблицу полученных данных.

Дальше строки нужно **привязать к тайтлу**: пары в блоке «Карта путей» — это
`вход vMix → элемент тайтла`. Клик по строке в виджете отправляет её значения в vMix
(`SetText` по каждому элементу).

Формат строки, который отдают все провайдеры: **ячейки через `|`**. Первая ячейка обычно
ключ или GUID, остальные — значения:

```
1|PlayerOne|1000
2|PlayerTwo|850
```

Пары «Карта путей» получают ячейки **по порядку**: первая пара — первая ячейка, вторая —
вторая, и так далее. Если ячеек меньше, чем пар, лишние пары получают пустую строку, а при
включённом «Перезапуск данных» значение берётся по кругу.

## JSON / HTTP API

| поле | что писать |
|---|---|
| Источник | `https://api.example.com/scores` или путь к файлу `scores.json` |
| JSONPath | `$.scores[*].team`, `$[0].name` |
| Группировка | сколько значений объединять в одну строку (обычно 1) |
| Заголовки | необязательно, по одному на строку: `X-Api-Key: secret`, `Authorization: Bearer …` |

Провайдер забирает JSON по HTTP(S) или из файла, вытаскивает значения по JSONPath и склеивает
их в строки через `|`. Заголовки нужны для API, требующих ключ.

## XML / HTTP

| поле | что писать |
|---|---|
| Источник | `http://127.0.0.1:8088/api` или путь к `.xml` |
| XPath | `./vmix/inputs/input/@number`, `/root/item/title` |
| Группировка | сколько узлов объединять в строку |

## Excel (`.xlsx`)

| поле | что писать |
|---|---|
| Файл | `/home/user/scores.xlsx` |
| Лист | имя листа (`Scores`) или его номер (`0`) |
| Начальная / конечная строка | `0` и `-1` (все) |
| Начальный / конечный столбец | `A` и `C` (можно буквами) |
| Таблица | включите, если первая строка — заголовки |

Читаются только значения: формулы берутся в том виде, в каком их посчитал Excel (кешированный
результат). Книга не открывается на запись, файл можно спокойно держать открытым.

## Google Sheets

Понадобятся две вещи: **ключ API** и **ссылка на таблицу** (или её ID).

1. Ключ: [console.cloud.google.com](https://console.cloud.google.com/) → создайте проект →
   **APIs & Services → Library → Google Sheets API → Enable** → **Credentials → Create
   credentials → API key**. Ключ выглядит как `AIza…`.
2. Доступ к таблице: **Файл → Настройки доступа → «Все, у кого есть ссылка» → Читатель**
   (иначе API вернёт 403).
3. В свойствах виджета: **Провайдер данных → Google Sheets**, затем

| поле | что писать |
|---|---|
| Ключ таблицы | `https://docs.google.com/spreadsheets/d/<ID>/edit` — можно вставить ссылку целиком |
| Ключ API | `AIza…` |
| Лист | номер листа, начиная с 0 |
| Диапазон | начальная/конечная строка и столбцы (`0`/`-1` = все) |
| Таблица | включите, если первая строка — заголовки |

Опрос идёт не чаще, чем раз в 5 секунд (ограничение квоты Google).

## NDI

| поле | что писать |
|---|---|
| Источник | имя NDI-источника (пусто — первый доступный) |
| Разметка | 0 = один источник, 1–4 = мультивью |
| Соотношение | `16:9` |
| Звук, Low bandwidth | по вкусу |

Нужен рантайм NDI (`libndi.so`): пакет `ndi-sdk` из AUR или официальный NDI SDK. Без него
виджет показывает тестовый сигнал и честно пишет «NDI (нет runtime: …)». Видео идёт в
интерфейс как MJPEG.

## Список из рук (без провайдера)

У виджета «Список» есть собственные строки в `.vmc` (`<Items>`). Они редактируются прямо в
панели свойств: блок **«Строки списка»** — поле на каждую строку, кнопки `↑` `↓` для порядка,
`✕` для удаления и **«Добавить строку»**. Формат тот же: `ключ|текст`.

Клик по строке в виджете применяет её к vMix: если источника нет, значения берутся из этих
строк (провайдер, если он подключён, имеет приоритет).

## Если данных нет

* под кнопкой «Обновить сейчас» всегда видно результат: число строк или текст ошибки
  (недоступный URL, 403 от Google, неверный JSONPath, отсутствующий файл);
* «Показать строки источника» показывает, что именно пришло — до привязки к тайтлу;
* проверьте «Карта путей»: имя элемента должно существовать у входа vMix (для
  `IsMappedToGUID` вход задаётся ключом-`GUID`, иначе — номером);
* период опроса — в свойстве «Период», в миллисекундах; при отладке удобно поставить 1000.
